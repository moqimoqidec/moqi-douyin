### 刘慈欣：我对人工智能是一种很爱的态度

- **作者**：@人民周刊
- **发布时间**：2026-10-10
- **链接**：https://www.douyin.com/video/7694844285291662655
- **点赞**：1.3万 | **评论**：5452 | **收藏**：2660 | **分享**：1743

近日，人民日报"在场"栏目专访科幻作家刘慈欣。谈到人工智能，刘慈欣用"很爱"来表达自己的态度。刘慈欣认为，不管是智力还是体力，人类是有天花板的。人类文明要想从地球扩展到整个宇宙，凭人类现在的能力，可能永远也做不到，可能需要依靠人工智能，冲破人类所先天拥有的局限。

"我对他们（人工智能）的感情是不一样的，并没有纠结到它是不是代替人类，甚至是不是征服人类。"刘慈欣说。
